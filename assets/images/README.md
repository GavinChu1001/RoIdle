Image folders for manually supplied game assets.

- `classes/`: class and character portrait sprites. Supports `.png`, `.gif`, `.webp`.
- `monsters/`: monster portraits and battle sprites. Supports `.png`, `.gif`, `.webp`.
- `battle-backgrounds/`: idle battle backgrounds. Supports `.png`, `.gif`, `.webp`.
- `equipment/`: equipment and set item icons. Supports `.png`, `.gif`, `.webp`.

Missing images are allowed. The game falls back to generated canvas art or CSS placeholders.
