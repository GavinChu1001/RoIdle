Place authorized job sprite files in this folder to replace the generated canvas characters.
Supported extensions are PNG, GIF, and WebP. The loader checks them in this order: `.png`, `.gif`, `.webp`.

Expected file names:

- novice
- swordman
- knight
- lordKnight
- runeKnight
- mage
- wizard
- highWizard
- warlock
- archer
- hunter
- sniper
- ranger
- acolyte
- priest
- highPriest
- archbishop
- merchant
- blacksmith
- whiteSmith
- mechanic
- thief
- assassin
- assassinCross
- guillotineCross

Use transparent images cropped around one standing/front-facing character. If a file is missing or fails to load, the game keeps using the built-in generated character drawing.
