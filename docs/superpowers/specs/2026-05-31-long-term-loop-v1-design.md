# 长期耐玩循环 V1 设计

## 背景

当前游戏已经有装备阶级、材料线、副本入口、技能 DPS、地图难度和装备联动雏形，但长期循环仍然偏散。玩家能变强，却不总是清楚今天该刷哪里、为什么刷、刷到的掉落是否会沉淀为长期收益。

本设计对标两个方向：

- 梅沃尔放置：通过技能、精通、任务、探索、副本和生产链，让玩家即使不推主线也能持续推进账号。
- RO 台服：通过装备、精炼、卡片、附魔、阶级强化和指定技能联动，让装备成为长期生态，而不是单件数值比较。

下一轮不继续堆新属性，而是先建立一条清晰的长期循环：目标指引、生产材料、定向补位、装备研究、Build 联动。

## 核心原则

1. 首页和冒险页保持干净，只服务战斗反馈。
2. 所有目标、建议、成长缺口和推荐路线进入独立的冒险手册。
3. 掉落、分解、生产、打造、副本和研究都要互相连接。
4. 玩家脸黑时可以靠材料和打造慢慢补位，但毕业词条仍然依赖长期刷取。
5. 每个系统都要能沉淀为账号长期收益，避免刷旧图和分解装备变成无意义行为。

## 首页和冒险页调整

首页不再显示“当前建议”类内容。

保留内容：

| 模块 | 目的 |
|---|---|
| 战斗区 | 展示核心挂机战斗 |
| Boss 进度 | 显示当前地图阶段目标 |
| 技能 DPS | 反馈当前输出来源 |
| 副本入口 | 快速进入每日玩法 |
| 最近掉落和收益 | 反馈挂机成果 |

移除或迁移内容：

| 模块 | 处理 |
|---|---|
| 当前建议 | 移入冒险手册 |
| 推荐评分 | 移入冒险手册 |
| 当前短板 | 移入冒险手册 |
| 推荐提升 | 移入冒险手册 |
| 查看战利品等建议句 | 移入冒险手册或任务提示 |

首页应该像战斗仪表盘，不像新手导师。玩家需要路线时主动打开冒险手册。

## 总路线

| 阶段 | 系统 | 目标 |
|---|---|---|
| P0 | 冒险手册 V1 | 今日目标、成长缺口、推荐地图、推荐材料、推荐副本 |
| P1 | 采矿 | 挂机产出精炼矿、阶级矿、装备升级通用材料 |
| P1 | 工匠 | 生产装备胚子、改良铭文、打造组件 |
| P2 | 装备打造 | 定向制作缺失部位，降低纯掉落随机挫败 |
| P2 | 装备补位 | 按装备线、部位、阶级制作目标装备 |
| P3 | 装备研究 | 掉落、分解、进阶都沉淀为装备线经验 |
| P3 | 地图熟练度 | 刷地图获得长期地区收益 |
| P4 | 副本 V2 | 每日词缀、材料瓶颈、副本奖励分层 |
| P5 | 卡片/装备/技能联动 | 精炼等级、卡片、装备线、技能增强形成 Build |
| P6 | 周期挑战 | 周常 Boss、周常副本、阶段奖励 |
| P7 | 长期收藏 | 装备图鉴、卡片图鉴、Boss 记录、地图完成度 |
| P8 | 社交和排行 | 单机循环稳定后再考虑 |

## P0 冒险手册 V1

冒险手册是长期循环入口，负责回答“我现在该做什么”。

### 页面定位

冒险手册可以作为独立页面，也可以先放在任务页顶部。它不进入冒险页右侧建议面板，避免首页重新变臃肿。

### 内容结构

| 区块 | 内容 |
|---|---|
| 今日目标 | 今日击杀、今日 Boss、今日副本、今日分解或打造 |
| 成长缺口 | 缺装备阶级、缺材料、缺精炼、缺技能等级 |
| 推荐地图 | 根据当前缺口推荐刷图地点 |
| 推荐材料 | 显示最缺材料、已有数量、主要来源 |
| 推荐副本 | 显示今天优先打的副本和原因 |
| 装备目标 | 当前最值得提升的装备线和部位 |
| 周常目标 | 进阶装备、完成副本、击败 Boss、累计材料 |
| 奖励 | 金币、材料、冒险研究点 |

### 冒险研究点

P0 先引入冒险研究点作为奖励和长期资源，但不急着做完整研究树。研究点先用于记录和展示，为 P1/P2 的生产和打造系统铺路。

冒险研究点来源：

- 每日目标
- 周常目标
- 首次完成某些阶段目标
- 后续副本和地图熟练度奖励

P0 不让研究点直接提供大量战力，避免新资源一上线就破坏数值。

## P1 生产技能 V1

生产技能先只做两个：采矿和工匠。暂不做炼金、狩猎、钓鱼等横向扩展。

### 采矿

定位：装备成长材料的长期来源。

产出：

- 精炼矿
- 阶级矿
- 稀有矿
- 少量装备进阶通用材料

成长方式：

- 挂机获得采矿经验
- 采矿等级解锁更高矿点
- 采矿精通提高产量和副产物概率

### 工匠

定位：装备打造和定向补位的前置生产线。

产出：

- 装备胚子
- 改良铭文
- 打造组件
- 装备线通用加工材料

成长方式：

- 消耗采矿产物进行加工
- 工匠等级影响加工效率和高阶材料解锁
- 工匠精通降低打造消耗或提高副产物

## P2 装备打造和定向补位

装备打造解决“有没有”，掉落和强化解决“好不好”。

打造允许玩家指定：

- 装备线，例如古代英雄、深渊、神殿
- 部位，例如武器、防具、鞋子、饰品
- 阶级，例如 T2、T3、T4

打造不允许玩家指定：

- 最佳随机词条
- 神话或暗金级别的超级稀有品质
- 完整毕业联动效果

这样玩家不会因为缺一件关键部位完全卡死，但仍然需要长期刷图和副本追求更好词条。

## P3 装备研究和地图熟练度

### 装备研究

装备掉落、分解、打造、进阶都给对应装备线研究经验。

例子：

| 行为 | 研究收益 |
|---|---|
| 掉落古代英雄装备 | 少量古代英雄研究经验 |
| 分解古代英雄装备 | 古代英雄材料和研究经验 |
| 进阶古代英雄装备 | 大量研究经验 |
| 首次获得某装备 | 图鉴登记和一次性奖励 |

装备研究提供小幅账号收益，例如材料掉率、打造折扣、装备线掉率、指定线精炼成本降低。收益应克制，作为长期沉淀，不作为通关钥匙。

### 地图熟练度

每张地图拥有熟练度。击杀、Boss、相关副本和材料目标都能增加熟练度。

地图熟练度可以提供：

- 该地图材料掉率
- 该地图金币或经验收益
- Boss 碎片掉率
- 地图来源提示
- 后续研究节点解锁

目标是让旧地图不会完全废弃。

## P4 副本 V2

副本从领奖按钮升级为材料瓶颈和玩法变化来源。

方向：

- 每日词缀
- 不同副本对应不同材料瓶颈
- 推荐战力和奖励分层
- 副本结果进入冒险手册目标

示例词缀：

| 词缀 | 影响 |
|---|---|
| 物理压制 | 怪物物理减伤提高 |
| 魔法屏障 | 怪物魔法减伤提高 |
| 首领狂化 | Boss 血量和奖励提高 |
| 材料丰收 | 材料奖励提高但怪物更硬 |
| 技能封锁 | 主动技能伤害降低 |

副本词缀的目标是让玩家根据当天环境调整装备和技能，而不是永远一套打穿。

## P5 Build 联动

Build 联动参考 RO 的装备、卡片、精炼、技能关系，但做简化和克制。

示例：

| Build | 条件 | 效果 |
|---|---|---|
| 古代英雄物理 | 古代英雄武器 + 精炼 5 + 剑士卡 | 一转和二转物理技能增强 |
| 深渊魔导 | 深渊法杖 + 魔法卡 + 地区研究 | 魔法技能伤害和异常命中提高 |
| 反击守护 | 高防装备 + 盾系卡 + 精炼总和 | 被击反击、格挡、回血增强 |
| Boss 猎手 | Boss 卡片 + 高阶武器 | Boss 伤害、破防、掉落提高 |

规则：

- 不做跨线大杂烩。
- 每个联动只强化少数技能或一种打法。
- 不让任意单套装备成为通关所有内容的钥匙。
- 联动依赖精炼等级时，以精炼为主，不看星炼和路线精通。

## P6-P8 后续方向

### 周期挑战

周常 Boss、周常副本、累计材料、指定装备进阶。奖励以研究点、材料和图鉴资源为主。

### 长期收藏

装备图鉴、卡片图鉴、Boss 记录、地图完成度。收藏提供小额账号收益和展示目标。

### 社交和排行

等单机循环稳定后再考虑排行榜、赛季、好友助力或公会。当前不优先做，避免在核心玩法还不稳时放大数值问题。

## 首轮实施范围建议

首轮只做 P0：冒险手册 V1。

包含：

- 从首页移除当前建议、推荐评分、当前短板、推荐提升。
- 新增冒险手册入口和页面或任务页模块。
- 展示今日目标、成长缺口、推荐地图、推荐材料、推荐副本、装备目标、周常目标。
- 新增冒险研究点字段，但只记录和发放，不开放研究树。
- 将现有材料来源、装备短板、Boss 进度、副本次数接入冒险手册。

不包含：

- 不实现采矿和工匠。
- 不实现装备打造。
- 不实现地图熟练度。
- 不实现副本词缀。
- 不实现新的卡片/装备/技能联动。
- 不做排行榜、赛季或社交。

## 验收标准

1. 冒险页不再显示当前建议、推荐评分、当前短板和推荐提升。
2. 冒险页仍保留战斗区、Boss 进度、技能 DPS、副本入口和最近收益反馈。
3. 冒险手册能显示今日目标、成长缺口、推荐地图、推荐材料、推荐副本和装备目标。
4. 每日和周常目标能正常初始化、归一化和保存。
5. 冒险研究点能作为奖励发放和显示，但不会直接提供战力。
6. 旧的任务页或目标系统不会与冒险手册产生重复入口或重复奖励。
7. `npm test` 和 `npm run check` 通过。

## 风险和处理

| 风险 | 处理 |
|---|---|
| 冒险手册变成另一个杂乱任务页 | P0 只显示路线和缺口，不塞所有系统详情 |
| 推荐逻辑不准确误导玩家 | 推荐只用明确数据，例如材料缺口、装备阶级、当前副本次数 |
| 新研究点破坏数值 | P0 只记录和发放，不开放战力加成 |
| 首页过度清理导致反馈不足 | 保留 Boss 进度、技能 DPS、副本入口和掉落收益 |
| 一次性范围过大 | 首轮只实现 P0，P1-P8 只作为路线保留 |
