# MVP铭刻系统设计

日期：2026-05-29  
状态：根据用户反馈定稿，等待实现计划  
范围：Rune Frontier Idle 的长期放置成长系统

## 背景

当前游戏已有几条成长线：

- BASE / JOB：角色基础等级与职业成长，主要由战斗经验推动。
- 转生：达到 BASE 上限后的重置突破，提升长期上限和稀有装备权重。
- 装备进度：从古代英雄、幻象、OS、信念、冰晶到莫卡迪斯/次元等装备层级推进。
- VIP、地图探索、技能成长、装备词条：提供局部加成和长期目标。

新增的 MVP铭刻系统用于补足一个长期成长层：玩家前台在线、在线击杀怪物、后台/离线挂机时都能积累“铭刻经验”。它应当像 RO 的 MVP 履历一样，从弱到强记录玩家击败过的首领气息，同时提供小幅、长期、不会被转生重置的成长。

## 目标

1. 玩家前台在线时自动积累铭刻经验。
2. 在线击杀有效等级怪物时获得额外铭刻经验。
3. 后台/离线收益结算也包含铭刻经验，按现有离线效率折算。
4. 铭刻经验满后自动提升铭刻等级。
5. 每 10 级需要一次手动突破，突破条件与现有战斗进度绑定。
6. MVP铭刻提供小幅常驻属性和阶段奖励。
7. 旧存档自动兼容，默认获得初始 MVP铭刻状态。

## 非目标

- 不做突破失败率。
- 不做铭刻技能树。
- 不做排行榜。
- 不做每日铭刻任务。
- 不做付费加速。
- 不重构 BASE/JOB、转生、装备系统。
- 不为了 MVP铭刻重写现有离线收益模型，只在现有离线奖励中增加一项铭刻经验。

## 核心定位

MVP铭刻是第三成长线：

```text
BASE / JOB = 战斗等级，短中期成长
转生 = 重置突破，提升上限
MVP铭刻 = 放置履历，长期累积，不重置
```

它的收益节奏应该适合网页放置游戏：

- 前台在线有稳定成长。
- 当前进度附近打怪会更快。
- 切后台或关闭页面也有离线铭刻经验。
- 高等级回低级图割草不给铭刻经验，避免滥刷。

## 推荐方案

采用“前台基础 + 怪物经验 + 离线折算 + 突破卡点”的混合方案。

对比过的方案：

| 方案 | 规则 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| 纯在线修行 | 前台在线每秒涨经验 | 简单、稳定 | 关闭页面就亏，不适合放置游戏 | 不采用 |
| 纯战斗修行 | 击杀、Boss、地图进度给经验 | 与战斗强绑定 | 强者滚雪球，低图滥刷风险高 | 不采用 |
| 在线 + 战斗 + 离线折算 | 前台稳定涨，击杀有效怪额外涨，离线按效率折算 | 符合放置游戏，也保留打怪推进感 | 需要低级图无效规则 | 采用 |

## 铭刻结构

MVP铭刻总共 100 级，分 10 个铭刻阶段，每个阶段 10 级。阶段名使用 RO / MVP 风格，从弱到强排列。

| 铭刻阶段 | 等级范围 | 对应阶段 | 主题 |
|---|---:|---|---|
| 波利王铭刻 | 1-10 | 新手、南门、伊甸园前期 | 入门 MVP 气息 |
| 黄金盗虫铭刻 | 11-20 | 下水道、早期刷图 | 防御、金币、早期首领 |
| 月夜猫铭刻 | 21-30 | 森林、挂机节奏 | 攻速、移动、巡猎 |
| 海盗之王铭刻 | 31-40 | 中期 Boss 输出 | 首领战、暴击、物理爆发 |
| 皮里恩铭刻 | 41-50 | 沙漠、命中、稳定输出 | DEX、命中、触发稳定性 |
| 兽人英雄铭刻 | 51-60 | 兽人、体质、生存 | VIT、生命、异常抗性 |
| 龟将军铭刻 | 61-70 | 高阶物理、最终伤害 | 最终物理、近远伤 |
| 多佩雷根铭刻 | 71-80 | 钟塔、攻速、爆发 | ASPD、普攻、节奏 |
| 黑暗领主铭刻 | 81-90 | 古城、暗魔法、Boss 压力 | MATK、技能伤害、暗属性 |
| 巴风特铭刻 | 91-100 | 神殿、终局 MVP | 溅射、最终伤害、终局象征 |

显示规则：

- 小等级显示为 `铭刻阶段 Lv.X`。
- 例如总等级 84 显示为 `黑暗领主铭刻 Lv.84`。
- 总等级 100 达到当前 V1 上限。

## 铭刻经验获取

铭刻经验有三种来源：

1. 前台基础经验：页面可见、窗口前台、游戏未暂停、角色存活时稳定增长。
2. 怪物经验：在线击杀有效等级怪物时获得额外经验。
3. 离线经验：后台/关闭页面后，随现有离线收益一起结算。

### 前台基础经验

基础公式：

```text
每分钟铭刻经验 = 10 × 地图倍率 × 难度倍率 × 转生倍率
```

地图倍率：

```text
地图倍率 = 1 + 当前地图序号 × 0.03
```

难度倍率：

| 难度 | 倍率 |
|---|---:|
| 普通 | 1.00 |
| 困难 | 1.20 |
| 深渊 | 1.45 |

转生倍率：

```text
转生倍率 = 1 + min(转生次数 × 0.03, 0.30)
```

前台在线判定：

- `document.hidden === false`。
- 窗口没有进入当前后台离线流程。
- 游戏未暂停。
- 角色当前生命大于 0。
- 铭刻未达到 Lv100。
- 铭刻不在未突破的 10 级卡点。

页面切后台或失焦后，不继续算前台在线基础经验；这段时间进入现有后台/离线结算，按离线经验规则处理。

### 怪物经验

在线击杀怪物额外获得铭刻经验：

```text
怪物铭刻经验 = 怪物基础铭刻经验 × 地图倍率 × 难度倍率 × 等级有效系数
```

怪物基础铭刻经验：

| 类型 | 基础铭刻经验 |
|---|---:|
| 普通怪物 | 0.20 |
| 变异怪物 | 0.45 |
| 精英怪物 | 0.60 |
| 普通 Boss | 8 |
| 地图 Boss 首杀 | 30 |
| 深渊 / 高阶 Boss | 12-20 |

有效等级规则：

- 怪物等级低于角色 BASE 等级 25 级以上时，不给铭刻经验。
- 当前地图低于历史最高解锁地图 2 张以上时，普通怪物、变异怪物、精英怪物不给铭刻经验。
- 重复刷低级 Boss 时，如果 Boss 等级低于角色 BASE 等级 25 级以上，不给铭刻经验。
- 地图 Boss 首杀永远给一次铭刻经验，但不能跨过未突破的 10 级卡点。
- 没有每分钟铭刻经验上限。

设计意图：

- 玩家刷当前进度图会自然成长。
- 高等级回低级图割草不会刷爆系统。
- Boss 首杀保留强反馈，鼓励推进地图。
- 不用“分钟上限”这类生硬限制。

### 离线经验

离线奖励包含铭刻经验。它不单独模拟“前台在线”，而是跟随现有离线击杀模型。

建议公式：

```text
离线铭刻经验 =
  有效离线击杀怪物铭刻经验总和
  + 离线基础铭刻经验
```

离线基础铭刻经验：

```text
离线基础铭刻经验 = 前台基础每分钟铭刻经验 × 离线分钟数 × 离线效率
```

离线击杀铭刻经验：

```text
离线击杀铭刻经验 = 按离线 killCount 估算的怪物铭刻经验 × 离线效率
```

规则：

- 复用现有离线效率，默认约 65%。
- VIP、卡片、装备带来的离线效率加成可以影响离线铭刻经验。
- 离线铭刻经验同样遵守低级图无效规则。
- 离线铭刻经验同样不能跨过未突破的 10 级卡点。
- 如果离线期间到达突破卡点，剩余离线铭刻经验不继续推进等级。
- 离线奖励弹窗显示“铭刻经验”一项。

## 升级曲线

当前等级升级所需铭刻经验：

```text
所需铭刻经验 = round(120 × 当前等级 ^ 1.45 × 铭刻阶段系数)
铭刻阶段系数 = 1 + 当前铭刻阶段序号 × 0.22
```

铭刻阶段序号从 0 开始：

- 波利王铭刻 = 0
- 黄金盗虫铭刻 = 1
- 月夜猫铭刻 = 2
- 以此类推

设计意图：

- Lv1-10 让玩家在当天能看到数次升级。
- Lv11-30 进入 1-3 天的成长节奏。
- Lv31-60 进入周级目标。
- Lv61-100 作为长线追求，不要求 V1 立刻填满所有内容。

## 突破规则

每 10 级需要突破一次。铭刻经验可以继续累计到当前等级所需上限，但不能跨过突破点。

突破点：

| 突破 | 条件 | 消耗 | 说明 |
|---|---|---|---|
| 10 -> 11 | BASE Lv20 | 无 | 从波利王进入黄金盗虫 |
| 20 -> 21 | 击败森林 Boss | 少量金币 | 进入月夜猫阶段 |
| 30 -> 31 | BASE Lv70 或完成关键转职进度 | 少量金币 | 进入海盗之王阶段 |
| 40 -> 41 | 解锁困难难度 | 中量金币 | 进入皮里恩阶段 |
| 50 -> 51 | 击败兽人首领或达成等价进度 | 兽人首领魂或金币 | 进入兽人英雄阶段 |
| 60 -> 61 | 击败矿洞/高阶 Boss 或获得高阶装备 | 高阶首领魂 | 进入龟将军阶段 |
| 70 -> 71 | 解锁钟塔或击败钟塔 Boss | 钟塔首领魂 | 进入多佩雷根阶段 |
| 80 -> 81 | 击败古城 Boss | 古城首领魂 | 进入黑暗领主阶段 |
| 90 -> 91 | 击败高阶 Boss 或达成终局开放条件 | 终局材料 | 进入巴风特阶段 |

突破原则：

- 突破没有失败率。
- 突破条件尽量复用已有进度和材料。
- 如果某些高阶材料尚未实装，V1 可以先把高阶突破标记为“后续版本开放”，但不影响 Lv1-60 的系统上线。

## 属性奖励

每级给小幅常驻成长：

| 属性 | 每级奖励 |
|---|---:|
| 最大生命 | +0.25% |
| 物理攻击 | +0.12% |
| 魔法攻击 | +0.12% |
| 防御 | +0.08% |

这些奖励应进入最终属性计算，但倍率要和现有装备、卡片、称号等来源清楚分层，避免重复乘法导致数值膨胀。

每个铭刻阶段突破后额外给阶段奖励：

| 铭刻阶段 | 突破奖励 |
|---|---|
| 波利王铭刻 | BASE/JOB 经验 +2% |
| 黄金盗虫铭刻 | 金币 +2% |
| 月夜猫铭刻 | 攻速或挂机效率 +1% |
| 海盗之王铭刻 | Boss 伤害 +2% |
| 皮里恩铭刻 | 命中/触发稳定性，或暴击 +1% |
| 兽人英雄铭刻 | 生命 +2%，异常抗性小幅提升 |
| 龟将军铭刻 | 物理最终伤害 +1% |
| 多佩雷根铭刻 | 普攻/攻速相关加成 |
| 黑暗领主铭刻 | 技能伤害 +2% 或 MATK +1% |
| 巴风特铭刻 | 最终伤害 +1.5% |

阶段奖励只在突破完成后生效。达到 10、20、30 等等级但未突破时，不提前获得下一阶段奖励。

## 数据模型

在存档中新增 `mvpInscription` 字段。

建议结构：

```javascript
mvpInscription: {
  level: 1,
  exp: 0,
  totalExp: 0,
  breakthroughLevel: 0,
  unlockedMarks: ["kingPoring"],
  bossFirstExpClaims: {},
  lastOnlineTickAt: Date.now()
}
```

字段含义：

| 字段 | 含义 |
|---|---|
| level | 当前 MVP铭刻总等级，范围 1-100 |
| exp | 当前等级内铭刻经验 |
| totalExp | 历史累计铭刻经验，用于统计和成就 |
| breakthroughLevel | 已完成突破的最高 10 级节点 |
| unlockedMarks | 已解锁铭刻阶段 id，用于显示或未来扩展 |
| bossFirstExpClaims | 已领取 Boss 首杀铭刻经验的记录 |
| lastOnlineTickAt | 上次前台在线铭刻结算时间 |

兼容规则：

- 旧存档没有 `mvpInscription` 时，初始化为 Lv1、exp 0。
- 非法等级修正到 1-100。
- 非法 exp 修正到 0。
- 如果 `breakthroughLevel` 高于当前等级，修正为当前已完成的 10 级节点。

## 系统组件

建议新增独立模块，不塞进战斗结算。

候选模块：

```text
src/systems/mvpInscription/
  mvpInscriptionData.js
  mvpInscriptionSystem.js
```

职责划分：

| 模块 | 职责 |
|---|---|
| mvpInscriptionData.js | 铭刻阶段、等级范围、突破条件、奖励表、曲线参数、怪物经验表 |
| mvpInscriptionSystem.js | 标准化存档、计算前台基础经验、计算怪物经验、计算离线经验、判断升级、判断突破、计算属性奖励 |
| characterPage.js | 显示 MVP铭刻卡片、进度条、突破按钮 |
| combat settlement 接入层 | 在线击杀怪物时调用铭刻经验结算 |
| offline.js 接入层 | 离线收益计算时加入铭刻经验 |
| main.js / game.js 接入层 | 把前台 tick、击杀结算、离线结算和属性计算接入现有运行时 |

## 数据流

前台在线 tick：

```text
主循环 tick
  -> 检查页面是否前台可见
  -> 检查是否可积累铭刻经验
  -> 计算 elapsed seconds
  -> 按每分钟铭刻经验换算本次增量
  -> 写入 mvpInscription.exp / totalExp
  -> 如果未处于突破卡点，自动升级
  -> 如果抵达突破卡点，停止跨级并提示可突破
  -> 触发轻量 UI 更新
```

在线击杀：

```text
怪物死亡结算
  -> 检查是否为在线战斗
  -> 识别普通怪、变异怪、精英怪、Boss、Boss 首杀
  -> 检查怪物等级和地图是否有效
  -> 计算怪物铭刻经验
  -> 写入 mvpInscription.exp / totalExp
  -> 复用升级与突破卡点逻辑
```

离线收益：

```text
calculateOfflineRewards
  -> 计算现有离线 killCount
  -> 按离线所在地图、难度、怪物等级判断是否有效
  -> 计算离线基础铭刻经验
  -> 计算离线击杀铭刻经验
  -> 乘以现有离线效率
  -> 写入 rewards.mvpInscriptionExp
  -> 领取离线奖励时加入 mvpInscription.exp / totalExp
  -> 如果抵达突破卡点，停止跨级
```

属性计算：

```text
computeStats
  -> getMvpInscriptionBonuses(state.mvpInscription)
  -> 合并 hpPct / atkPct / matkPct / defensePct / gold / bossDamage / finalDamage 等加成
```

突破：

```text
玩家点击突破
  -> 检查当前等级是否在 10/20/30...
  -> 检查条件
  -> 检查消耗
  -> 扣除材料/金币
  -> 更新 breakthroughLevel
  -> 解锁下一个铭刻阶段
  -> 允许继续升级
  -> 写日志和提示
```

## UI 设计

放在角色页，靠近“转生声望”和成长工作台。

卡片信息：

```text
MVP铭刻：黑暗领主铭刻 Lv.84
铭刻经验：12,430 / 18,900
前台修行：14.8 / 分钟
怪物铭刻：当前地图有效
离线铭刻：按离线效率 65% 折算
下一突破：巴风特铭刻，需要击败高阶 Boss
```

UI 元素：

- MVP铭刻阶段和等级。
- 铭刻经验进度条。
- 前台修行速度。
- 当前地图怪物铭刻是否有效。
- 离线铭刻效率提示。
- 当前加成摘要。
- 下一个突破条件。
- 到达突破点时显示“突破”按钮。

交互规则：

- 未到突破点时不显示突破按钮。
- 到突破点但条件未满足时，按钮禁用并显示缺少条件。
- 条件满足时，按钮可点击。
- 突破成功后写入日志，并显示短提示。
- 离线奖励弹窗中显示“铭刻经验 +X”。

## 错误处理

1. 页面后台挂起后恢复：后台时间走现有离线收益，产生离线铭刻经验，不补算前台基础经验。
2. 浏览器时间异常：前台 tick 单次有效秒数设置上限，例如最多 60 秒，避免手动改系统时间刷前台经验。
3. 角色死亡：前台基础经验停止；离线收益按现有离线战斗是否可获得收益来决定。
4. 存档缺字段：标准化补齐。
5. 高阶突破条件依赖未实装材料：条件表可以返回“后续版本开放”，按钮禁用。
6. 达到 Lv100：停止积累铭刻经验，显示已达上限。
7. 重复 Boss 首杀：只给普通 Boss 铭刻经验，不重复给首杀奖励。
8. 低级图无效：UI 显示“当前地图过低，怪物不给铭刻经验”。

## 测试计划

- 旧存档能补齐 `mvpInscription`。

- Boss 首杀铭刻经验只领取一次。

- 离线铭刻经验受现有离线效率影响。
- 暂停、死亡、Lv100、未突破卡点时不继续跨级。
- 突破条件不满足时失败且不扣材料。

## 接受标准

1. 旧玩家打开游戏不会丢档或报错。
2. 新玩家默认显示 `波利王铭刻 Lv.1`。
3. 前台在线时铭刻经验自动增长。
4. 在线击杀有效等级怪物时获得铭刻经验。
5. 后台/离线收益包含铭刻经验，并受现有离线效率影响。
6. 高等级打低级图不会获得怪物铭刻经验。
7. 小铭刻等级可自动升级。
8. 每 10 级必须突破，未突破不能进入下一铭刻阶段。
9. MVP铭刻属性能在角色属性中体现。
10. 角色页能清楚展示当前铭刻、经验进度、前台速度、当前地图有效性、离线效率、下一突破条件。
11. 离线奖励弹窗能显示铭刻经验。
12. `npm test` 和 `npm run check` 通过。
