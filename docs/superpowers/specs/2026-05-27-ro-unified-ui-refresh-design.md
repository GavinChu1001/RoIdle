# 符文边境全站 UI 统一优化设计

日期：2026-05-27  
状态：已由用户确认视觉方向，待实施计划

## 目标

在不调整战斗数值、掉率、装备属性、技能公式和存档结构的前提下，统一游戏各页面的视觉语言与信息层级，使玩家：

- 进入冒险页时，立即看懂当前战斗、技能、首领进度和收益。
- 进入角色页时，立即看懂评分、短板和下一步提升方向。
- 进入装备页时，更快完成筛选、对比和操作。
- 进入铁匠铺时，不混淆精炼、星炼与打孔。
- 在其余养成页面中，优先看到有价值的信息和可领取内容。

## 已确认的设计方向

整体方案采用 `A+C` 融合结构：

- 全站框架采用顶部主分页与内容工作区，保留现有操作习惯。
- 冒险页以紧凑战斗控制台为主，保持战斗现场感。
- 角色、装备、铁匠铺等成长页面采用仪表盘式信息组织。
- 视觉气质采用温暖羊皮纸底色，并使用更明显的 RO 木质招牌风按钮。

用户已确认：

- 不采用全站左侧主导航作为第一版框架。
- 关键按钮采用木牌风格。
- 木质效果集中在操作控件，不让整个页面变得厚重。

## 全站框架

### 顶部区域

顶部保持轻量、稳定的全局信息结构：

- 品牌与游戏名称。
- 金币、BASE 等级、战力、背包容量等核心概览。
- 登录/存档相关入口沿用已有功能位置，不改变行为。

### 主分页导航

继续使用顶部分页，统一分页按钮的：

- 高度、边框、圆角和文字居中方式。
- 当前页高亮状态。
- 窄屏换行与可读性。

主分页不做过度厚重的木牌效果，使用轻量木纹/羊皮纸标签即可，确保页面多、切换频繁时仍然轻便。

### 内容工作区

每个页面采用相同的卡片层级：

- 页面标题与当前状态摘要。
- 核心信息卡片。
- 次要详情折叠或放在下方。
- 操作按钮保持统一尺寸、间距和状态反馈。

## 视觉语言

### 配色

主色调：

- 页面背景：温暖米白、羊皮纸色。
- 卡片背景：更浅的奶白色，和主背景形成层级。
- 主操作色：木质棕色搭配金色细节。
- 状态辅助色：深绿色用于已选择、可用或成功状态。

品质和特殊来源颜色仅用于标题、徽标或边框点缀：

- 史诗：柔和紫色。
- 传说：金褐色。
- 暗金：深紫褐色。
- 神话：柔和金色。
- 深渊：暗紫色。

避免大面积强发光、持续闪烁和刺眼渐变。

### RO 木牌按钮

按钮按使用频率分层：

#### 关键操作按钮

用于：

- 挑战首领
- 开始精炼
- 开启孔位
- 领取重要奖励

风格：

- 木质渐变底色。
- 金色铆钉或细边装饰。
- 清晰的按压与悬停反馈。
- 字体保持高对比度。

#### 常规操作按钮

用于：

- 装备、锁定、查看详情、打开页面等。

风格：

- 较浅的木纹/羊皮纸按钮。
- 比关键操作按钮更轻。
- 保持统一高度与间距。

#### 筛选、页签与小标签

用于：

- 装备筛选。
- 铁匠铺标签页。
- 品质、来源、用途标签。

风格：

- 轻量边框和浅背景。
- 不使用厚重木牌装饰。
- 通过颜色与边框区分选中态。

## 页面设计

## 冒险页

冒险页是主要体验页，目标是同时提供战斗反馈与挂机效率信息。

### 主区域

显示：

- 当前地图与难度。
- 怪物/首领战斗画面。
- 怪物名称与生命条。
- 伤害数字与技能施放提示。
- 灼烧、中毒、冰冻等当前目标状态。
- 主动技能栏及冷却状态。

### 右侧信息区

分为三张紧凑卡片：

1. 当前目标
   - 首领进度。
   - 自动挑战状态。
   - 挑战首领与查看地图操作。

2. 最近收益
   - 装备掉落数量。
   - 自动分解数量。
   - 最高品质。
   - 查看战利品与整理装备入口。

3. 成长提醒
   - 可精炼装备。
   - 可领取任务。
   - 需要处理的背包或成长事项。

### 反馈原则

- 技能释放、暴击、Boss 登场、高品质掉落可以短暂高亮。
- 不使用长时间闪烁。
- 不让反馈遮挡战斗操作和信息阅读。

## 角色页

角色页的目标是回答“我现在缺什么”。

### 顶部摘要

显示：

- 角色名与职业。
- BASE/JOB 等级与转生信息。
- 当前地图/难度。
- 综合评分。
- 当前成长目标。

### 核心评分

首屏展示：

- 综合评分。
- 输出评分。
- 生存评分。
- Boss 评分。
- 深渊评分。
- 打宝评分。

### 战斗重点与短板

并列展示：

- 攻击、生命、防御、暴击、吸血等重要属性。
- 当前短板，例如深渊减伤不足、Boss 伤害偏低。
- 推荐提升动作，例如强化防具、整理装备、挑战首领。

### 来源概览

展示主要属性来源：

- 装备。
- 精炼/星炼。
- 卡片。
- 套装。
- 称号。
- 冒险者荣誉。
- 深渊词条。

详情可展开，首屏不堆满完整数值。

## 装备页

装备页的目标是回答“这件值不值得换、下一步能做什么”。

### 列表区域

装备列表仅显示摘要：

- 名称。
- 品质。
- 部位和等级。
- 精炼/星炼状态。
- 深渊、套装、神话、暗金等关键标签。
- 推荐用途。

筛选栏保持固定高度和统一尺寸，不因装备数量变化而变形。

### 详情区域

选中装备后显示：

- 名称、品质、部位/子类型、孔位等基础信息。
- 综合、输出、生存、Boss、深渊、打宝等评分。
- 核心属性摘要。
- 替换预估差异。
- 可展开的完整属性、套装、赋能、精炼、星炼、孔位详情。

### 操作区域

操作按钮使用统一紧凑布局：

- 装备/卸下。
- 精炼。
- 打孔。
- 锁定/解锁。
- 查看详情。
- 分解。

高风险操作继续保留原有确认流程，界面改造不改变业务行为。

## 铁匠铺

铁匠铺的目标是让成长机制互不混淆。

### 标签页

页面拆分为：

- 装备精炼。
- 装备星炼。
- 装备打孔。
- 套装打造。
- 时装打造。
- 材料说明。

### 操作页统一结构

每个成长标签页显示：

- 当前装备预览。
- 当前等级或孔位状态。
- 本次目标变化。
- 成功率或规则说明。
- 消耗材料与金币。
- 关键操作木牌按钮。

明确显示：

- 精炼使用 `+N`。
- 星炼使用 `★N`。
- 打孔使用孔位数量。

## 其他页面

### 地图与图鉴

- 首屏展示摘要与进度。
- 奖励、掉落、属性效果分区。
- 详情通过展开查看，避免长页面堆叠。

### 卡片

- 普通卡明确显示“持有生效”。
- Boss 卡明确显示“插卡生效”。
- 来源、用途、觉醒与镶嵌说明分区排列。

### 任务与商店

- 可领取和可购买内容优先显示。
- 奖励与价格使用清晰的资源展示。
- 操作按钮按重要程度使用木牌主按钮或轻量次按钮。

### VIP / 公告 / 日志

- 冒险者荣誉使用摘要卡片显示等级、当前加成和下一特权。
- 公告和日志保持阅读优先，长内容折叠或分页。

## 响应式布局

桌面端：

- 冒险页使用战斗主区域 + 右侧信息区。
- 装备页使用列表 + 详情双栏。
- 铁匠铺使用选择装备 + 操作信息双栏。

窄屏/移动端：

- 主分页允许整齐换行或横向滚动。
- 冒险页右侧卡片移动到战斗区域下方。
- 装备列表和详情改为上下排列。
- 铁匠铺标签可横向滑动，操作卡片单列。
- 木牌按钮保持触控尺寸，但不过度增高。

## 实施边界

本次 UI 优化不得修改：

- 战斗数值与伤害公式。
- 技能倍率与技能机制。
- 装备生成、属性计算与掉率。
- 精炼、星炼、打孔成功率和消耗规则。
- 地图难度和掉落表。
- 账号、存档字段与旧存档兼容逻辑。

允许修改：

- 页面结构与信息顺序。
- CSS 样式、按钮体系、卡片体系、响应式布局。
- 显示层必要的摘要组合与折叠交互。
- 战斗已有反馈信息的视觉呈现。

## 验收标准

- 全站页面拥有一致的卡片、按钮、页签和标签风格。
- 木牌风格重点操作按钮具有 RO 氛围，但常规操作仍然轻便。
- 冒险页一屏能看到战斗、状态、技能、首领目标和近期收益。
- 角色页能快速看懂评分、短板与来源。
- 装备页能快速筛选、对比和操作装备。
- 铁匠铺中精炼、星炼与打孔不混淆。
- 页面在移动端与窄屏下无明显溢出或按钮错位。
- UI 改动不改变已有游戏规则、数值和存档行为。

## 实施策略

为避免当前工作区已有功能改动互相干扰，实施时按可验证的小批次推进：

1. 建立全站样式变量、木牌按钮和通用卡片样式。
2. 优先改冒险页框架与战斗右侧信息区。
3. 改角色页分区展示。
4. 改装备页列表和详情布局。
5. 改铁匠铺标签与操作卡片。
6. 逐步统一卡片、地图、图鉴、任务、商店、VIP、公告与日志页面。
7. 每批完成后做页面截图与现有交互回归。
