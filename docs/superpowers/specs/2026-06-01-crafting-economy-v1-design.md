# 装备打造经济 V1 设计

## 背景

当前装备掉落率偏高，这本身是好事：放置游戏需要持续掉东西，玩家才会觉得挂机有反馈。但如果装备打造只是另一种“生成装备”的入口，它会和高频掉落互相抢定位，最后变成鸡肋。

本设计把两者拆开：

- 掉落负责爽感、临时换装、分解燃料和稀有惊喜。
- 打造负责高成本、可预期、定向补位和长期毕业目标。

P4 副本 V2、P6 周期挑战、P8 社交排行先不进入本轮。P1、P2、P3、P5、P7 都纳入这一轮：先建立装备经济主干，再把 Build 联动和长期收藏接上，让装备掉落、打造、研究和收集形成完整闭环。

## 核心原则

1. 高频掉落不削成低频掉落，而是让大量装备变成打造燃料。
2. 打造装备必须比普通掉落更可靠，但不能直接替代神话、暗金和完美词条追求。
3. 打造解决“我缺这一件”的问题，掉落解决“我能不能遇到惊喜”的问题。
4. 材料来源要能被冒险手册和材料背包解释清楚，玩家知道去哪刷、为什么刷。
5. 打造成本要随着阶级明显上升，让高阶装备有长期目标感。

## 当前范围

| 优先级 | 系统 | 本轮定位 |
|---|---|---|
| P1 | 采矿 | 挂机产出阶级矿、精炼矿、少量通用硬材料 |
| P1 | 工匠 | 把矿石和材料加工成装备胚子、改良铭文、打造组件 |
| P2 | 装备打造 | 定向制作指定装备线、阶级、部位、物理或魔法定位的装备 |
| P2 | 装备补位 | 解决缺关键部位导致无法推进装备线的问题 |
| P2 | 打造熟练度 | 每次打造获得经验，高等级解锁暗金和神话大师打造 |
| P3 | 装备研究 | 掉落、分解、打造、进阶都沉淀为装备线经验 |
| P3 | 地图熟练度 | 刷对应地图积累地区收益，强化材料来源意义 |
| P5 | 卡片/装备/技能联动 | 以精炼等级、装备线、卡片和少量技能增强形成 Build 目标 |
| P7 | 长期收藏 | 装备图鉴、卡片图鉴、Boss 记录、地图完成度沉淀为长期目标 |

暂不做：

- 副本每日词缀和副本奖励重做。
- 周常 Boss、周常副本、周期挑战奖励。
- 排行、好友、公会、社交目标。
- 跨线大杂烩式 Build 联动。

## 掉落定位

地图掉落保持相对爽快，不把装备变成罕见事件。

掉落装备承担四个职责：

| 职责 | 说明 |
|---|---|
| 即时反馈 | 玩家挂机时经常看到装备进包，有获得感 |
| 临时换装 | 掉到明显更好的装备时可以直接穿 |
| 分解燃料 | 大量无用装备变成装备线材料、打造材料和研究经验 |
| 稀有惊喜 | 神话、暗金、优秀词条仍主要通过掉落制造惊喜 |

掉落不保证：

- 指定部位。
- 指定物理或魔法定位。
- 指定核心词条。
- 指定神话或暗金。
- 指定毕业联动效果。

## 打造定位

打造是高成本保底，不是低成本抽奖。

打造允许玩家指定：

| 可指定项 | 示例 |
|---|---|
| 装备线 | 古代英雄、OS、深渊、神殿 |
| 阶级 | T2、T3、T4、T5 |
| 部位 | 武器、防具、鞋子、饰品 |
| 定位 | 物理、魔法、通用兜底 |

打造不允许玩家指定：

| 不可指定项 | 原因 |
|---|---|
| 神话或暗金 | 保留超级稀有追求 |
| 完美词条组合 | 保留长期刷装空间 |
| 满星炼或高精炼 | 避免绕过成长系统 |
| 完整毕业联动 | Build 仍需要掉落、精炼、卡片和技能组合 |

打造装备应具备：

- 基础属性下限高于同阶普通掉落。
- 初始词条数量稳定，不出现明显废品。
- 可作为进阶路线的可靠起点。
- 可以继续强化、精炼、星炼、进阶和分解。

## 成本结构

打造成本分三层，每层都服务一个玩法目的。

| 成本层 | 材料例子 | 目的 |
|---|---|---|
| 通用成本 | 金币、阶级矿、精炼矿 | 消耗长期基础资源 |
| 装备线成本 | 古代英雄残片、OS 零件、深渊结晶、神殿印记 | 让玩家刷对应地图有意义 |
| 定向成本 | 武器胚子、防具胚子、饰品胚子、改良铭文、打造组件 | 让工匠系统成为打造前置 |

高阶打造成本应明显高于低阶：

| 阶级 | 成本节奏 |
|---|---|
| T2 | 让玩家体验定向补位，成本较轻 |
| T3 | 需要稳定分解和基础生产，开始形成目标 |
| T4 | 需要对应地图材料、阶级矿和工匠组件共同投入 |
| T5 | 作为长期毕业目标，成本高且需要装备研究或地图熟练度支持 |

## 采矿

采矿是装备成长的长期基础材料来源。

产出：

- 精炼矿。
- 阶级矿。
- 稀有矿。
- 少量装备进阶通用材料。

成长：

- 挂机获得采矿经验。
- 采矿等级解锁更高矿点。
- 采矿精通提高产量和副产物概率。

限制：

- 采矿不能直接产出完整装备。
- 采矿不能替代地图线材料。
- 采矿产出主要补“硬材料”，不补“装备线身份材料”。

## 工匠

工匠是打造的加工系统。

产出：

- 装备胚子。
- 改良铭文。
- 打造组件。
- 装备线通用加工材料。

作用：

- 把采矿产物、分解材料和金币转成可用于打造的中间材料。
- 让玩家即使不推图，也能通过生产线慢慢积累打造资源。
- 给金币增加长期用途。

限制：

- 工匠不直接产出毕业装备。
- 工匠等级影响加工效率和高阶组件解锁。
- 高阶打造仍需要对应地图或装备线材料。

## 打造熟练度与大师打造

打造熟练度是生产线的长期等级。它不只提供折扣，而是决定玩家能否制作更高稀有度的定向装备。

经验来源：

- 每次装备打造获得打造经验。
- 打造更高阶装备获得更多经验。
- 打造暗金或神话装备获得大量经验。
- 首次打造某条装备线、某个部位或某个阶级可获得一次性经验奖励。

等级解锁：

| 打造等级 | 解锁内容 |
|---|---|
| Lv.1-20 | T2/T3 普通定向打造 |
| Lv.21-40 | T4/T5 高阶定向打造，成品基础下限提高 |
| Lv.41-60 | T6/T7 精密打造，可选择更稳定的物理、魔法或通用倾向 |
| Lv.61-80 | 暗金大师打造，需要图纸、核心材料、大量分解材料和金币 |
| Lv.81-100 | 神话大师打造，需要完整图纸、稀有核心、装备线研究等级和巨量金币 |

大师打造规则：

- 暗金和神话打造是极高成本确定获得，不做低概率赌博。
- 大师打造只能保证稀有度、装备线、阶级、部位和定位。
- 大师打造不保证完美词条、满星炼、满精炼或最佳 Build 联动。
- 天然掉落仍可能出现更好的词条组合，保留掉落惊喜。

图纸来源：

| 来源 | 图纸收益 |
|---|---|
| 首次击败关键 Boss | 解锁对应装备线的基础图纸碎片 |
| 图鉴完成度 | 补齐部位或阶级图纸碎片 |
| 分解暗金或神话装备 | 获得高稀有图纸碎片或大师打造凭证 |
| 地图熟练度 | 解锁该地区装备线的图纸购买或兑换 |
| 装备研究等级 | 作为高阶暗金和神话打造门槛 |

打造熟练度与装备研究分工：

| 系统 | 解决的问题 |
|---|---|
| 打造熟练度 | 我作为工匠能不能做出更高稀有度装备 |
| 装备研究 | 我对某条装备线理解够不够深 |
| 图纸 | 我有没有掌握这件装备的制作方法 |
| 材料 | 我有没有真的刷够资源 |

这样玩家的长期目标会从“等掉落”变成“刷材料、拆装备、补图纸、升工匠、做目标装备”。

## 分解与研究

大量掉落装备通过分解进入长期沉淀。

分解产出：

| 来源装备 | 产出 |
|---|---|
| 普通装备 | 少量装备线材料、基础分解材料 |
| 高阶装备 | 更多装备线材料、阶级材料 |
| 神话或暗金 | 稀有分解材料、更多研究经验 |
| 已强化装备 | 按规则返还部分投入材料 |

装备研究经验来源：

- 掉落指定装备线装备。
- 分解指定装备线装备。
- 打造指定装备线装备。
- 进阶指定装备线装备。

装备研究提供克制型收益：

- 对应装备线材料掉落小幅提高。
- 对应装备线打造成本小幅降低。
- 对应装备线分解返还小幅提高。
- 对应装备线打造解锁更高阶配方。

装备研究不提供大额直接战斗力，避免变成新的数值膨胀源。

## 地图熟练度

地图熟练度让刷图不只为了当前掉落。

增长来源：

- 击杀普通怪。
- 击败 Boss。
- 获得该地图关键材料。
- 获得该地图装备线掉落。

收益：

- 该地图材料掉落小幅提高。
- 该地图金币或经验收益小幅提高。
- 冒险手册中显示更清晰的材料来源提示。
- 后续可作为高阶打造或研究节点的解锁条件。

地图熟练度服务于材料目标，不在本轮做复杂地区天赋树。

## Build 联动 V1

Build 联动让装备不只比较面板数值，而是开始形成“我为什么刷这一线装备”的答案。

本轮只做克制、清晰、可解释的联动：

| 联动来源 | 规则 |
|---|---|
| 装备线 | 同一装备线提供核心主题 |
| 精炼等级 | 作为主要门槛，不看星炼和路线精通 |
| 卡片 | 作为 Build 倾向补强 |
| 技能 | 每个 Build 只增强少数相关技能 |

联动原则：

- 不做跨线大杂烩。
- 不让单个套装直接通关全部内容。
- 每条装备线最多先做一个核心机制。
- 每个核心机制有 3 个精炼门槛升级。
- 一转、二转、三转职业都能吃到部分增强，避免旧技能完全废弃。

示例方向：

| Build | 核心机制 | 精炼门槛方向 |
|---|---|---|
| 古代英雄物理 | 普攻和物理技能形成稳定输出循环 | 精炼提高物理技能倍率、冷却节奏或额外打击 |
| OS 魔导 | 魔法技能获得持续爆发或异常收益 | 精炼提高魔法技能伤害、异常命中或技能连动 |
| 深渊猎手 | 面向 Boss 和高难地图的破防输出 | 精炼提高 Boss 伤害、破甲或斩杀窗口 |
| 神殿守护 | 生存、反击和持续作战 | 精炼提高减伤、反击、吸血或技能回复 |

本轮不追求一次做完所有职业的完整毕业 Build，但要把数据结构、展示方式和至少一批可用联动做出来。

## 长期收藏 V1

长期收藏把“刷到过”也变成进度，不让装备只剩穿和分解两个结果。

收藏内容：

| 收藏线 | 记录内容 |
|---|---|
| 装备图鉴 | 首次获得装备线、阶级、部位、稀有度 |
| 卡片图鉴 | 首次获得卡片、卡片星级或来源 |
| Boss 记录 | 首杀、击杀次数、最快击杀、掉落记录 |
| 地图完成度 | Boss 进度、地图熟练度、关键材料发现 |

收藏奖励保持克制：

- 少量金币、材料或冒险研究点。
- 小幅账号经济收益。
- 来源提示和图鉴完成度展示。

收藏不提供大额直接战斗力，避免变成新的必刷数值墙。

## 玩家循环

目标循环：

1. 玩家在冒险手册看到缺少某个部位或材料。
2. 玩家去对应地图挂机，获得装备、金币、材料和地图熟练度。
3. 不需要的装备被分解，转成装备线材料和研究经验。
4. 采矿持续产出阶级矿和精炼矿。
5. 工匠把矿石和分解材料加工成胚子、铭文和组件。
6. 每次打造获得打造经验，逐步解锁更高阶配方。
7. 玩家用高成本打造指定装备线、阶级、部位和定位的装备。
8. 高等级工匠消耗图纸和大量材料进行暗金或神话大师打造。
9. 打造装备成为可靠起点，继续强化、精炼、进阶或被更稀有掉落替代。
10. 精炼、卡片和装备线触发 Build 联动，让目标装备拥有玩法差异。
11. 掉落、Boss、地图和卡片被记录进收藏，形成长期完成度。

## UI 影响

本轮会影响以下界面方向：

| 界面 | 调整方向 |
|---|---|
| 冒险手册 | 增加“可打造目标”“缺口材料”“推荐生产动作” |
| 材料背包 | 材料按装备线和用途展示，未拥有材料默认不显示 |
| 装备页 | 增加打造入口或跳转，不堆太多单件装备按钮 |
| 生产页 | 新增采矿、工匠、打造熟练度和大师打造入口 |
| 图鉴或收藏页 | 展示装备、卡片、Boss 和地图完成度 |
| 装备详情 | 展示当前可激活或未达成的 Build 联动门槛 |

UI 原则：

- 不把所有材料来源塞进每一行，避免材料页臃肿。
- 详细来源交给冒险手册和材料详情弹层。
- 装备页只展示装备决策，不承担完整生产系统。

## 平衡基准

打造吸引力来自可靠性，而不是直接碾压。

建议基准：

| 项目 | 目标 |
|---|---|
| 同阶普通掉落 | 可能好也可能差，作为常规替换和分解来源 |
| 同阶打造装备 | 基础属性下限更高，词条更稳定，适合作为进阶底胚 |
| 同阶神话或暗金 | 仍应明显优于普通打造，作为长期惊喜 |
| 高一阶普通装备 | 大多数情况下应优于低一阶普通装备 |
| 低阶高强化装备 | 可以短期过渡，但不应长期压过高一阶成长线 |

打造不追求“一造毕业”，而是让玩家明确知道下一件目标怎么得到。

## 验收标准

1. 玩家能理解掉落装备为什么仍然有意义：穿、分解、研究、惊喜。
2. 玩家能理解打造装备为什么值得做：定向、稳定、可进阶、下限高。
3. P1、P2、P3、P5、P7 可以形成完整闭环，不依赖 P4、P6、P8。
4. 打造材料至少来自掉落分解、地图材料、采矿、工匠四条路径。
5. 高阶打造成本明显高于低阶，形成长期目标。
6. 冒险手册能解释缺什么、去哪刷、能不能打造。
7. 材料背包不会因为显示全部未拥有材料而变得臃肿。
8. 至少一批装备线拥有可解释的 Build 联动，且不会单件装备碾压全部内容。
9. 装备、卡片、Boss 和地图至少能记录基础收藏进度。
10. 每次打造能获得打造经验，打造等级能解锁更高阶和更高稀有度配方。
11. 暗金和神话大师打造需要图纸、装备线研究等级和大量材料，不能绕过掉落追求完美词条。

## 风险与处理

| 风险 | 处理 |
|---|---|
| 打造太便宜，掉落失去意义 | 打造只能保底补位，不能指定神话、暗金和完美词条 |
| 打造太贵，玩家感觉没进度 | T2-T3 成本较轻，先让玩家体验定向补位 |
| 材料系统过于复杂 | 材料按装备线、阶级和用途分组，未拥有材料默认隐藏 |
| 采矿和工匠变成孤立系统 | 采矿产出硬材料，工匠产出打造中间件，两者都接入装备打造 |
| 数值继续膨胀 | 装备研究和地图熟练度只给小幅经济收益，不给大额直接战斗力 |

## 首轮实施边界

下一份实施计划应只覆盖：

- 采矿 V1。
- 工匠 V1。
- 装备打造 V1。
