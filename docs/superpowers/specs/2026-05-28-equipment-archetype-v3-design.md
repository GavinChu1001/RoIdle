# 装备 V3：物理 / 魔法 / 通用定位系统设计

日期：2026-05-28
项目：Rune Frontier Idle
状态：已确认设计，等待实施计划

## 背景

装备 V2 已经解决了一批明显问题：移除死属性、让格挡真正生效、合并重复乘区、提高部分基础属性价值，并提供旧装备重算和重铸券补偿。

但装备系统仍然缺少长期放置游戏最重要的三件事：

- 掉落不够有方向，玩家拿到装备后仍然主要看总评分。
- 养成目标不够明确，重铸更像随机赌博，而不是朝目标打造。
- 背包判断成本高，玩家很难快速知道一件装备该穿、该留、该洗还是该分解。

本设计把“标签”升级为装备底层定位。定位不是 UI 说明，而是装备生成、重铸、评分、筛选和自动决策的依据。

## 核心目标

1. 装备掉落时一眼能看出路线：物理、魔法或通用。
2. 装备属性池按定位倾斜，减少明显废词条。
3. 重铸可以围绕目标定位进行，形成“好胚子 -> 定向打造”的循环。
4. 背包筛选、自动换装、自动分解保护都参考定位价值。
5. 为未来双修技能保留空间，避免把所有装备硬塞进物理或魔法。

## 非目标

- 不在本轮制作大规模名装库。
- 不在本轮制作锁词条、词条继承、装备升阶等深层养成。
- 不再次强制重置旧装备属性。
- 不把职业系统整体重做为双修职业。
- 不把装备定位做成纯 UI 标签。

## 装备定位

每件装备新增字段：

```js
archetype: "physical" | "magic" | "general"
```

显示名称：

| 值 | 显示 | 定义 |
| --- | --- | --- |
| `physical` | 物理 | 偏 ATK、STR、DEX、攻速、暴击、吸血和物理输出 |
| `magic` | 魔法 | 偏 MATK、INT、DEX、技能伤害、回响和魔法输出 |
| `general` | 通用 | 偏生存、收益、离线、材料、刷宝，以及未来双修兜底 |

定位的优先级：

1. 稀有度决定强度预算。
2. 定位决定预算花在哪里。
3. 模板、地图、Boss、职业只影响定位权重或固定定位。

## 定位生成规则

装备生成时按混合规则决定定位：

1. 模板固定优先。
   Boss 装、套装件、特殊模板可以直接指定 `archetype`。

2. 部位和基础属性提供默认倾向。
   武器根据 ATK/MATK 判断物理或魔法；防具、鞋子、饰品默认更容易通用，但仍可出现物理或魔法倾向。

3. 当前职业轻微影响。
   物理职业提高物理定位权重，魔法职业提高魔法定位权重，未来双修职业可以同时提高物理和魔法权重。该影响不能锁死其他定位掉落。

4. 地图和 Boss 可以调整倾向。
   例如矿洞可以更偏物理防具，钟塔可以更偏魔法饰品，南门新手装备可以更偏通用。

推荐基础权重：

| 场景 | 物理 | 魔法 | 通用 |
| --- | ---: | ---: | ---: |
| 物理职业普通掉落 | 45 | 25 | 30 |
| 魔法职业普通掉落 | 25 | 45 | 30 |
| 双修或未知职业 | 35 | 35 | 30 |
| 防具/鞋子/饰品默认修正 | -5 | -5 | +10 |

具体数值可以在实施中按现有装备产出体验微调，但第一版要保持“轻影响”，不能变成职业绑定掉落。

## 属性池倾斜

定位影响随机词条池，而不是硬性排除所有其他属性。

物理池优先：

- `atk`
- `str`
- `dex`
- `attackSpeedPct`
- `critRatePct`
- `critDamageBonus`
- `lifeSteal`
- `bossDamageBonus`
- `finalDamageBonus`

魔法池优先：

- `matk`
- `int`
- `dex`
- `skillDamageBonus`
- `echoChance`
- `finalDamageBonus`
- `baseExpBonus`
- `jobExpBonus`
- `bossDamageBonus`

通用池优先：

- `hp`
- `def`
- `vit`
- `damageReductionPct`
- `blockRate`
- `dodgeRatePct`
- `drop`
- `rareDropBonus`
- `equipmentDrop`
- `cardDrop`
- `materialQuantityBonus`
- `offlineEfficiencyBonus`

保留少量交叉词条：

- 物理装备可以出现少量生存和 Boss 词条。
- 魔法装备可以出现少量生存和经验词条。
- 通用装备可以出现少量攻击词条，但不应成为主输出装备。

## 掉落变爽

掉落反馈要从“获得一件装备”变成“获得一件有路线的装备”。

第一版规则：

- 新装备生成后带定位。
- 高品质装备更容易显示为明确路线，例如“史诗 · 物理 武器”。
- 若装备定位与当前职业路线匹配，掉落播报可显示“职业适配”。
- 若装备品质较高且定位契合度高，显示“可打造胚子”。
- Boss 或地图固定倾向装备可以在名称或播报中体现来源。

示例播报：

- 获得 史诗 · 物理 武器：枫木短剑
- 获得 传说 · 魔法 饰品：幸运铃铛
- 获得 稀有 · 通用 胚子：旅人披风

“爽感”来自可判断性，不是简单提高掉落数量。

## 养成目标

重铸分为三类：

### 重铸券重铸

- 消耗装备重铸券。
- 可免费重铸一次。
- 可以保留当前定位，也可以指定物理、魔法、通用。
- 主要用于补偿、活动和稀有奖励。

### 普通重铸

- 不消耗重铸券。
- 消耗金币、露恩石、精炼矿。
- 保留装备当前定位。
- 重洗基础随机词条和机制词条。

### 定向重铸

- 不消耗重铸券。
- 消耗更多金币、露恩石、蓝晶碎片。
- 可以指定物理、魔法或通用定位。
- 史诗及以上额外消耗星界碎片。
- 传说及以上额外消耗古代核心。
- 神话额外消耗神话精粹。

第一版不做锁词条和继承。重铸结果至少保证一部分词条来自目标定位池，避免玩家付出定向成本后仍然得到明显错配装备。

## 背包筛选与判断

装备页新增定位筛选：

- 全部
- 物理
- 魔法
- 通用
- 职业适配
- 可打造胚子
- 可分解

装备卡显示：

- 定位：物理 / 魔法 / 通用
- 职业适配：适配 / 可用 / 不适配
- 胚子判断：高品质且定位词条契合时显示

自动换装：

- 物理职业优先物理评分。
- 魔法职业优先魔法评分。
- 通用装备作为生存、收益、离线和未来双修兜底。
- 若装备总评分更高但定位严重不适配，不应盲目替换核心输出装备。

自动分解保护：

- 高品质装备默认保护。
- 当前职业适配装备保护。
- 定位契合度高的装备保护。
- 通用高收益装备保护。
- Boss、套装、特殊来源装备继续保护。

## 评分模型

装备评分需要增加定位维度：

- `physicalScore`
- `magicScore`
- `generalScore`
- `archetypeFit`

综合评分仍可保留，但不能作为唯一判断。

装备的主推荐由定位和分数共同决定：

- 物理装备优先展示物理评分。
- 魔法装备优先展示魔法评分。
- 通用装备优先展示通用评分。
- 当前职业路线会影响“推荐当前职业”的判断，但不改变装备本身定位。

## 旧装备迁移

旧装备加载时不重置属性，只自动推断定位。

推断规则：

- ATK、STR、攻速、暴击、暴伤、吸血明显高于魔法侧 -> 物理。
- MATK、INT、技能伤害、回响明显高于物理侧 -> 魔法。
- 生存、掉落、经验、材料、离线收益占主导 -> 通用。
- 物理和魔法接近，或无法判断 -> 通用。

迁移只补字段，不发放额外补偿，不清空旧装备强化、卡槽或词条。

## 数据与代码边界

建议新增或集中以下纯逻辑：

- 装备定位常量和显示名。
- `inferEquipmentArchetype(item, context)`：旧装备和模板推断。
- `rollEquipmentArchetype(template, context)`：新装备生成定位。
- `getArchetypeStatPools(archetype)`：定位词条池。
- `calculateArchetypeScores(item)`：定位评分。
- `getEquipmentFitTags(item, state)`：职业适配和胚子判断。
- `getReforgeCost(item, targetArchetype, mode)`：普通/定向重铸成本。

这些逻辑应优先放进 `src/systems/equipment/`，`game.js` 保留当前运行时接线和 UI 入口，避免继续把规则散落在渲染模板里。

## 测试要求

至少覆盖：

- 新装备生成后一定有合法 `archetype`。
- 旧装备 normalize 后能推断定位。
- 当前职业只轻微影响定位权重，不锁死其他定位。
- 物理定位更容易获得物理词条。
- 魔法定位更容易获得魔法词条。
- 通用定位更容易获得生存/收益词条。
- 定向重铸会改变或保留目标定位，并消耗正确材料。
- 重铸券可以免费触发一次定位重铸。
- 装备评分产生物理、魔法、通用分。
- 自动换装不再只按总评分盲目替换不适配装备。
- 自动分解保护高价值适配装备和通用高收益装备。

## 验收标准

- 装备页能看到每件装备的物理 / 魔法 / 通用定位。
- 新掉落装备带定位，且掉落播报能体现高价值定位装备。
- 装备属性明显更少出现路线错配。
- 旧存档加载不崩溃，旧装备自动补全定位。
- 玩家可以按物理 / 魔法 / 通用筛选背包。
- 玩家可以用重铸券或材料进行保留定位/定向定位重铸。
- 自动换装和自动分解保护会参考定位。
- `npm test` 和 `npm run check` 通过。

## 风险与控制

- 风险：定位系统过强会让掉落变窄。
  控制：当前职业只轻微影响，地图和模板也只是倾向，不锁死。

- 风险：通用装备变成垃圾或万能。
  控制：通用专注生存和收益，不和物理/魔法争主输出。

- 风险：重铸成本太复杂。
  控制：第一版只用现有材料，不新增货币。

- 风险：`game.js` 继续膨胀。
  控制：评分、定位、成本和推断逻辑优先放在 `src/systems/equipment/`，`game.js` 只做桥接。

## 实施切片建议

1. 定义定位常量、推断函数和评分函数。
2. 接入新装备生成与旧装备 normalize。
3. 调整随机词条池和重铸逻辑。
4. 更新装备页显示、筛选和掉落播报。
5. 更新自动换装和自动分解保护。
6. 补测试并跑完整验证。
