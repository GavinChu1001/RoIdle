# 战斗难度与装备成长平衡设计

## 背景

当前后期体验出现三类叠加失衡：

- 星座套装可以直接掉落，基础属性和套装效果过强，拿到后会跳过大量装备成长。
- V3 技能二转后开始指数放大，主动技能等级成长、冷却缩短、多段/终结/额外触发叠在一起，8000 面板也能打出几十万伤害。
- 后期地图尤其深渊、神殿的怪物曲线追不上技能与套装爆发，导致后期地图失去压力。

这次目标不是把怪物血量粗暴加高，而是同时压住超模来源、抬高后期检验线，并让装备阶级成为玩家继续刷装的主动力。

## 目标

1. 取消所有星座套装掉落，让星座套不再破坏正常装备路线。
2. 将星座套定位为收藏、打造、未来特殊玩法奖励，属性是锦上添花，不是通关钥匙。
3. 降低 V3 技能指数成长，让二转后仍然变强，但不会直接无痛通关。
4. 抬高后期普通、困难、深渊地图难度，重点补足 HP、防御和少量减伤。
5. 拉开装备阶级基础倍率，使高阶白板装备有机会替换低阶高品质装备。

## 非目标

- 不重做职业技能体系。
- 不调整前期新号生存压力。
- 不删除星座套收藏、星座分解、星座圣卡材料。
- 不改服务器存档结构。
- 不做 UI 大改，只补必要说明或测试断言。

## 方案

### 星座套装

星座套装从常规掉落链路中移除：

- 在线击杀不再调用或产生星座套装备。
- 离线收益不再产生星座套装备。
- 保留星座套数据、收藏、分解和圣卡材料逻辑，避免后续玩法断档。
- 地图掉落说明不再暗示星座套会掉落。

星座套属性整体降温：

- 星座部件基础数值压到当前约 30%-45%。
- 五件套输出类效果从 20%-35% 降到约 6%-12%。
- 经济类效果从极端值降到可感知但不爆表，例如金牛从金币 +500% 改为金币 +35%、BASE/JOB 经验 +12%、材料数量 +10%。
- 深渊星座收藏加成也保持轻量，避免再次成为深渊通关核心。

### V3 技能

技能保留爽感，但降低指数爆炸：

- 主动技能每级伤害成长从 1.12 调整到约 1.06。
- 主动技能冷却成长从 0.94 调整到约 0.97。
- 主动技能最低冷却从 2.2 秒提高到 3.5-4 秒。
- 高爆发机制单独降温：终结技、即死转伤害、多段额外触发、额外释放。
- 保留职业差异，不把所有技能削成同一种数值。

### 怪物曲线

前期不抬攻击，避免新号死亡问题回归。主要调整后期：

- 普通古城、深渊湖、神殿：提高 HP 和防御，让普通后期不再被秒清。
- 困难古城、深渊湖、神殿：比普通后期更明显提升 HP、防御和推荐战力。
- 深渊全线：提高 HP、防御和少量减伤，使其承担装备检验功能。
- 攻击提升保持克制，优先用“杀得慢”和“Boss 检验”制造压力。

### 装备阶级

装备阶级优先级高于稀有度：

- 提高 T3-T10 的基础倍率斜率。
- 控制稀有度品质浮动，避免低阶神话长期压过高阶普通。
- T3 白板应明显有机会替换 T2 普通成品。
- T5 之后每阶差距更明显，让玩家看到刷下一阶的直接收益。

## 关键改动范围

- `data.js`
  - V3 技能默认成长。
  - 星座套计划与套装效果。
  - 难度配置、后期地图推荐战力和基线倍率。

- `src/systems/drops/bossDrops.js`
  - 在线星座套掉落关闭或改为 0 产出。

- `src/systems/offline.js`
  - 离线星座套掉落关闭。

- `src/systems/combat/skillMechanics.js`
  - 主动技能最低冷却和高爆发机制降温。

- `src/systems/combat/monster.js`
  - 后期困难/深渊基线曲线。

- `src/systems/equipment/itemProgression.js`
  - T3-T10 阶级倍率。

- `scripts/test.mjs`
  - 新增断言覆盖星座不掉落、技能冷却下限、阶级倍率和后期难度曲线。

## 验收标准

1. `npm test` 和 `npm run check` 通过。
2. 星座套不会从在线击杀、Boss 击杀、离线收益中直接掉落。
3. 星座套仍可在图鉴/收藏/分解相关逻辑中被识别。
4. V3 主动技能不会因为等级和冷却叠加变成近似无冷却爆发。
5. 后期地图不会再被二转技能与星座套轻松秒清。
6. 高阶装备基础属性相对低阶装备有明确提升，玩家有刷下一阶的动机。

## 风险

- 技能削弱过重会让职业成长失去爽感，所以优先降低指数成长和极端机制，不全面砍基础倍率。
- 星座掉落关闭后，相关成就和收藏会变慢，需要后续通过打造或活动补来源。
- 后期怪物曲线提高后，材料掉落和装备掉落收益需要同步保持吸引力，避免只是变慢。
